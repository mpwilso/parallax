# Evals

`cases.toml` is the case set: real, already-merged fixes to small open-source projects, in the SWE-bench instance shape, with the humans' tests hidden from the agents and used to score.

`results/` holds the runs from 2026-09-28. They came from an earlier harness that ran on the first design (a maker working straight from a goal) and was removed with it. Their numbers describe that path, not the current one.

A new harness on the current pipeline (`parallax do`, with Focus, Maker and Second Eye) is planned work; see the README's "What's next" and [docs/history.md](../docs/history.md).
